Welcome to the official SCALLY clothing brand website, a streetwear-inspired online platform designed to showcase clothing collections and help customers place orders easily.

👕 About SCALLY

SCALLY is a clothing brand built around casual style, individuality, and confidence. The website provides a simple way for customers to explore the brand and connect with us to place orders.

✨ Features

- 🏠 Home section introducing the SCALLY brand
- 🛍️ Shop section for showcasing clothing products
- 👕 Streetwear-inspired brand design
- 📱 Responsive design for mobile and desktop
- 💬 WhatsApp ordering for customer enquiries and purchases
- 🎨 Dark theme with neon-green accents

🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling and layout
- JavaScript — Interactive features

📲 How to Order

Customers can use the WhatsApp ordering feature on the website to contact SCALLY, enquire about products, and place orders.

🔧 Run Locally

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. For editing, open the project in Acode or another code editor.

🌐 Deployment

This website can be published using GitHub Pages.

1. Open the repository's Settings.
2. Select Pages.
3. Choose Deploy from a branch.
4. Select the "main" branch and the "/(root)" folder.
5. Save and wait for deployment.
